# Predictive-Modelling-on-a-Web-Scraped-Data-with-a-Power-BI-Dashboard

Made a Python web scraper to harvest 230+ raw records, done end-to-end data cleaning, handling missing values/duplicates, and performing Exploratory Data Analysis (EDA) to uncover core data trends and feature correlations.


Trained and evaluated a [Regression / Clustering] model to derive predictive insights, translating complex ML outputs into an interactive Power BI dashboard with actionable recommendations for business decision-making.
